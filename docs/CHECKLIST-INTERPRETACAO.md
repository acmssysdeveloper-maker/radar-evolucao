# Checklist de interpretação — Radar de Evolução 2.4.3

## Objetivo
Transformar as oito notas em uma leitura contextual, começando pelo desenvolvimento humano e relacionando as demais dimensões sem fazer afirmações que as respostas não sustentam.

## Regras preservadas
- Pontuação original: resposta 0–4; média por dimensão; conversão para 0–10 por multiplicação de 2,5.
- Índice geral: média das oito dimensões.
- Níveis: Reativo 0–2,4; Organizado 2,5–4,4; Estruturado 4,5–6,4; Adaptativo 6,5–8,2; Evolutivo 8,3–10.
- Roda de Evolução permanece inalterada como visual principal.
- Lead_ID, Diagnostico_ID, CRM, privacidade, WhatsApp, PWA e estrutura de páginas não foram removidos.

## Motor contextual
1. Sempre inicia a leitura pelo desenvolvimento humano.
2. Depois observa relações com pensamento crítico, processos, dados, decisão, tecnologia, aprendizagem e inovação.
3. Considera relações entre dimensões, não apenas a menor nota.
4. Usa linguagem condicional: sugere, merece observar, vale investigar.
5. Não inventa causas, fatos ou características da empresa.
6. Evita metáforas e clichês promocionais de IA.
7. Mostra uma ordem de observação para orientar reflexão e não para impor uma conclusão.

## Validações executadas
- Sintaxe dos JavaScript principais: aprovada.
- Referências locais em HTML: aprovadas.
- Extremos matemáticos 0, 2, 5, 7,5 e 10: aprovados.
- 200 combinações aleatórias de respostas: aprovadas.
- Verificação de linguagem proibida no motor: aprovada.
- Resultado e relatório usam a mesma fonte de interpretação.
